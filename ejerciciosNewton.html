Ejercicio 7

Aplicar el método de Newton-Raphson para obtener una aproximación de la raíz de la función:

f(x) = 3.1230x3 + 3.5480x2 + 0.0543x - 0.0896 = 0

Fórmula / Derivada

f'(x) = 3(3.1230x2) + 2(3.5480x) + 0.0543

f'(x) = 9.3690x2 + 7.0960x + 0.0543

xn+1 = xn - [ (3.1230xn3 + 3.5480xn2 + 0.0543xn - 0.0896) / (9.3690xn2 + 7.0960xn + 0.0543) ]

Tabla de iteraciones

n xn

Conclusión: La aproximación obtenida al cabo de la tercera iteración es x = 0.1432.
