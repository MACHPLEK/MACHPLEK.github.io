Ejercicios de Bisección Abierta

Aplicación del método de punto fijo para encontrar aproximaciones de raíces.

Ejercicio 1

Aplicar el método de punto fijo para establecer una aproximación de la raíz de:

f(x) = 2e^(x²) - 5x

Valor inicial: x₀ = 0

Error: εₐ = 0.01

Despejes

g₁(x) = (2e^(x²))/5

Tabla de iteraciones

n x g₁(x) f(x)
0 0 0.4 1
1 0.4 0.4694 0.1478
2 0.4694 0.4985 0.058
3 0.4985 0.5128 0.0278
4 0.5128 0.5203 0.014
Conclusión: La aproximación obtenida en la última iteración es x ≈ 0.5203.

Ejercicio 4

Tabla de iteraciones
