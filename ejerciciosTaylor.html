Ejercicios por Método de Taylor

Aplicación del polinomio de Taylor para encontrar aproximaciones de funciones.

Ejercicio 1

Utilizando el polinomio de tercer orden, centrado en a = 1, para aproximar:

f(x) = e1.2

Polinomio de tercer orden (a = 1):

P3(x) = f(1) + f'(1)(x - 1) + [f''(1) / 2!](x - 1)2 + [f'''(1) / 3!](x - 1)3

Tabla de iteraciones / Cálculos

Orden (n) Término Valor Parcial
0 e 2.718281828
1 e(0.2) 0.543656365
2 [e / 2](0.2)2 0.054365636
3 [e / 6](0.2)3 0.003624375
Resultado / Conclusión: La aproximación obtenida es e1.2 ≈ 3.3216 (con 4 decimales).

Ejercicio 5

Utilizando una función de cuarto grado centrada en a = 2 para aproximar:

f(x) = 1 / x,    para aproximar f(2.4) = 1 / 2.4

Fórmula general del polinomio de Taylor (Grado 4):

P4(x) = f(2) + f'(2)(x - 2) + [f''(2) / 2!](x - 2)2 + [f'''(2) / 3!](x - 2)3 + [f(4)(2) / 4!](x - 2)4

Derivadas y evaluación en a = 2

Orden Derivada f(n)(x) Evaluación f(n)(2)
0 1 / x 1 / 2 = 0.5
1 -1 / x2 -1 / 4 = -0.25
2 2 / x3 2 / 8 = 0.25
3 -6 / x4 -6 / 16 = -0.375
4 24 / x5 24 / 32 = 0.75

Sustitución en x = 2.4 (donde x - 2 = 0.4)

P4(2.4) = 0.5 - 0.25(0.4) + 0.125(0.4)2 - 0.0625(0.4)3 + 0.03125(0.4)4

P4(2.4) = 0.5 - 0.1 + 0.02 - 0.004 + 0.0008 = 0.4168

Resultado / Conclusión: P4(2.4) = 0.4168 con un error aproximado Ea ≈ 0.4667.

Ejercicio 6

Aproximación de cuarto grado centrada en a = 1 para evaluar:

f(x) = ln(x + 1),    para aproximar ln(2.5)

Desarrollo de derivadas evaluadas en a = 1:

  • f(1) = ln(2)
  • f'(1) = 1 / 2
  • f''(1) = -1 / 4
  • f'''(1) = 1 / 4
  • f(4)(1) = -3 / 8

Sustitución para x = 1.5 (con x - 1 = 0.5)

P4(1.5) = ln(2) + (1/2)(0.5) - (1/4 / 2!)(0.5)2 + (1/4 / 3!)(0.5)3 - (3/8 / 4!)(0.5)4

Resultado / Conclusión: ln(2.5) ≈ 0.96128 con error Ea ≈ 0.96128.

Ejercicio 7

Polinomio de cuarto grado centrado en a = 1 para aproximar una función exponencial:

f(x) = ex,    aproximando para x = 1.1

Cálculo de términos y sustitución:

P4(1.1) = e [ 1 + 2(0.1) + 3(0.1)2 + (10/3)(0.1)3 + (14/6)(0.1)4 ]

P4(1.1) = e [ 1 + 0.2 + 0.03 + 0.003333 + 0.000317 ] = e(1.2336) ≈ 3.3534

Resultado / Conclusión: El valor aproximado es e1.1 ≈ 3.3534 con un error relativo Er ≈ 0.00227.
