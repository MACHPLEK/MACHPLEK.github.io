Errores

Aprende sobre los diferentes tipos de errores que pueden aparecer al realizar cálculos numéricos.

Error absoluto

Es la diferencia entre el valor real y el valor aproximado obtenido mediante un método numérico.

Ea = |Valor real - Valor aproximado|

Mientras menor sea el error absoluto, más cercana será la aproximación al valor real.

Error relativo

Indica qué tan grande es el error en comparación con el valor real. Permite evaluar la precisión de una aproximación.

Er = Ea / |Valor real|

El error relativo suele expresarse como un número decimal y puede convertirse a porcentaje.

Error porcentual

Expresa el error relativo como un porcentaje, lo que facilita interpretar qué tan grande es la diferencia entre el valor real y el valor aproximado.

Er% = Er × 100

Por ejemplo, un error porcentual de 2% significa que la aproximación presenta una diferencia del 2% respecto al valor real.

Error aproximado

Se utiliza cuando no conocemos el valor real de la solución. En su lugar, se comparan dos aproximaciones consecutivas para saber cuánto ha cambiado el resultado.

Ea = |Aproximación actual - Aproximación anterior|

Si el error aproximado disminuye, significa que las aproximaciones están convergiendo hacia una solución.
