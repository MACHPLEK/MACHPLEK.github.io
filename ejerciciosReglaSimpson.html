Ejercicio 5

Aplica la regla compuesta de Simpson 1/3 con n = 4, n = 8 y n = 16, estima el error por refinamiento de malla y analiza el orden de convergencia.

I = ∫₀² e⁻ˣ² dx

Subintervalos: n = 4, n = 8, n = 16

Fórmula de error: E ≈ |S₂ₙ - Sₙ| / 15

Orden del error global

El error global es O(h⁴) porque el error local O(h⁵) se acumula n/2 = (b - a)/(2h) veces.

Tabla comparativa

n h Sₙ Error estimado
4 0.500 0.8818124 —
8 0.250 0.8820655 1.687 × 10⁻⁵

Conclusión: Al duplicar n (reducir h a la mitad), el error disminuye aproximadamente por un factor de 16 (2⁴), confirmando que la regla compuesta de Simpson 1/3 tiene precisión de orden O(h⁴).
