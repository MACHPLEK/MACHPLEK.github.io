EJERCICIO #1

Tenemos F(x) = x² - x - 1 encontrar la raiz en el intervalo [ 0,2 ] para n = 5 y un error de 8%



Iteración 1

Primero tendremos que evaluar las funciones de inicio y final (referencia a los intervalos [ 0,2 ])


EVALUAMOS:

f ( Xi ) = f ( 0 ) = ( 0² ) - 0 - 1 = - 1

f ( Xf ) = f ( 2 ) = ( 2² ) - 2 - 1 = 1


Despues de evaluar los intervalos, tendremos que calcular Xm

CALCULAMOS Xm:

Xm = 2 + 0 / 2 = 1


Ahora que tenemos Xm vamos a redefinir los intervalos para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1 ) = ( 1 )² - 1 - 1 = - 1

f ( Xi ) = f ( 0 ) = ( 0² ) - 0 - 1 = - 1


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados
para saber en la dirección que va, recordando que Xm = Xi si el resultado es positivo y Xm = Xf si es negativo:

- 1 * - 1 = 1


Como el resultado salio positivo podemos decir que Xm va a ser Xi en el nuevo intervalo.

Dato: Como es la primera iteración normalmente el error que calculemos nos dara el 100%
asi que el error se puede calcular desde la 2da iteración

Iteración 2

Despues de hacer la primera iteración, se tendra que volver hacer casi el mismo
procedimiento para las demas iteraciones hasta llegar al error minimo deseado.


NUEVO INTERVALO:

[ 1,2 ]


Despues se tendra que calcular nuevamente Xm con los nuevos intervalos

CALCULAMOS Xm:

Xm = 2 + 1 / 2 = 1.5


Ahora que tenemos Xm nuevamente vamos a redefinir los intervalos una vez más para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.5 ) = ( 1.5 )² - 1.5 - 1 = - 0.25

f ( Xi ) = f ( 1 ) = ( 1² ) - 1 - 1 = - 1


Siguiendo los pasos de la iteración 1, tendremos que multiplicar el resultado para saber en la dirección que va nuevamente y ver los intervalos nuevos:

- 0.25 * - 1 = 0.25


Como el resultado salio positivo nuevamente, Xm va a ser Xi en el nuevo intervalo.

Ahora bien, se va hacer un paso más para esta iteración ya que necesitamos saber el porcentaje de error que se obtuvo en esta iteración y si se encuentra la raiz en esta iteración

ERROR:

| 1.5 - 1 / 1.5 | * 100 = 33.3%


no es equivalente o menor al 8% de error que buscamos.

Iteración 3

Siguiendo con las iteraciones, nuevamente tendremos un intervalo nuevo


NUEVO INTERVALO:

[ 1.5,2 ]


Tendremos que calcular nuevamente Xm

CALCULAMOS Xm:

Xm = 2 + 1.5 / 2 = 1.75


Una vez que tengamos Xm se podria calcular el porcentaje de error para ver si proseguir con las iteraciones y ya no redefinir los intervalos (en este caso nos dan las iteraciones que debemos tener, sin embargo se puede usar cuando no te dan la cantidad de intervalos para usar)

ERROR:

| 1.75 - 1.5 / 1.75 | * 100 = 14.29%


no es equivalente o menor al 8% de error que buscamos, entonces seguiremos con el paso de redefinición de intervalos para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.75 ) = ( 1.75 )² - 1.75 - 1 = 0.3

f ( Xi ) = f ( 1.5 ) = ( 1.5² ) - 1.5 - 1 = - 1


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados
para saber en la dirección que va nuevamente

0.3 * - 1 = - 0.3


Como el resultado salio negativo esta vez, podemos decir que Xm va a ser Xf en el nuevo intervalo.

Iteración 4

Despues de hacer la tercera iteración, se tendra que volver hacer casi el mismo
procedimiento para las demas iteraciones hasta llegar al error minimo deseado.


NUEVO INTERVALO:

[ 1.5,1.75 ]


Despues se tendra que calcular nuevamente Xm con los nuevos intervalos

CALCULAMOS Xm:

Xm = 1.75 + 1.5 / 2 = 1.63


Ahora que tenemos Xm nuevamente vamos a redefinir los intervalos una vez más para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.63 ) = ( 1.63 )² - 1.63 - 1 = 0.0269

f ( Xi ) = f ( 1.75 ) = ( 1.75² ) - 1.75 - 1 = 0.3125


Siguiendo los pasos de las demas iteraciones, tendremos que multiplicar el resultado para saber en la dirección que va nuevamente y ver los intervalos nuevos:

0.0269 * 0.3125 = 0.00840625


Como el resultado salio positivo, Xm va a ser Xi en el nuevo intervalo.

Se va a calcular el porcentaje de error que se obtuvo en esta iteración y si se encuentra la raiz en esta iteración

ERROR:

| 1.63 - 1.5 / 1.63 | * 100 = 7.98%


Es equivalente o menor al 8% de error que buscamos, asi que nos quedaremos con este valor para este problema.



EJERCICIO #2

Tenemos F(x) = x³ - x² - 1 encontrar la raiz en el intervalo [ 1,2 ] con una tolerancia de 1/16 = 0.06



Iteración 1

Primero tendremos que evaluar las funciones de inicio y final (referencia a los intervalos [ 1,2 ])


EVALUAMOS:

f ( Xi ) = f ( 1 ) = 1³ - 1² - 1 = - 1

f ( Xf ) = f ( 2 ) = 2³ - 2² - 1 = 3


Despues de evaluar los intervalos, tendremos que calcular Xm

CALCULAMOS Xm:

Xm = 2 + 1 / 2 = 1.5


Ahora que tenemos Xm vamos a redefinir los intervalos para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.5 ) = 1.5³ - 1.5² - 1 = 0.125

f ( Xi ) = f ( 1 ) = 1³ - 1² - 1 = - 1


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados
para saber en la dirección que va, recordando que Xm = Xi si el resultado es positivo y Xm = Xf si es negativo:

0.125 * - 1 = -0.125


Como el resultado salio negativo podemos decir que Xm va a ser Xf en el nuevo intervalo.

Iteración 2

Despues de hacer la primera iteración, se tendra que volver hacer casi el mismo
procedimiento para las demas iteraciones hasta llegar al error minimo deseado.


NUEVO INTERVALO:

[ 1,1.5 ]


Despues se tendra que calcular nuevamente Xm con los nuevos intervalos

CALCULAMOS Xm:

Xm = 1.5 + 1 / 2 = 1.25


Ahora que tenemos Xm nuevamente vamos a redefinir los intervalos una vez más para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.25 ) = 1.25³ - 1.25² - 1 = - 0.60

f ( Xi ) = f ( 1 ) = 1³ - 1² - 1 = - 1


Siguiendo los pasos de la iteración 1, tendremos que multiplicar el resultado para saber en la dirección que va nuevamente y ver los intervalos nuevos:

- 0.60 * - 1 = 0.60


Como el resultado salio positivo, Xm va a ser Xi en el nuevo intervalo.

Ahora bien, se va hacer un paso más para esta iteración ya que necesitamos saber el porcentaje de error que se obtuvo en esta iteración y si se encuentra la raiz en esta iteración

ERROR:

| 1.25 - 1.5 / 1.25 | = | - 0.2 | = 0.2 > 0.06


en este caso como estamos trabajando con tolerancia podemos no multiplicarlo por 100 y dejar los decimales para comparar si el valor es mas alto o bajo que la tolerancia, sin embargo se puede sacar el porcentaje de la tolerancia al multiplicarlo por 100, pero en este ejercicio ocuparemos la primera opcion.

Iteración 3

Siguiendo con las iteraciones, nuevamente tendremos un intervalo nuevo


NUEVO INTERVALO:

[ 1.25,1.5 ]


Tendremos que calcular nuevamente Xm

CALCULAMOS Xm:

Xm = 1.5 + 1.25 / 2 = 1.375


Una vez que tengamos Xm se podria calcular la tolerancia de error para ver si proseguir con las iteraciones y ya no redefinir los intervalos (en este caso no nos dan las iteraciones que debemos tener)

ERROR:

| 1.375 - 1.25 / 1.375 | = 0.090 > 0.06


no es equivalente o menor a 0.06 de tolerancia que buscamos, entonces seguiremos con el paso de redefinición de intervalos para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.375 ) = 1.375³ - 1.375² - 1 = - 0.30

f ( Xi ) = f ( 1.25 ) = 1.25³ - 1.25² - 1 = - 0.60


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados
para saber en la dirección que va nuevamente

- 0.30 * - 0.60 = 0.18


Como el resultado salio positivo esta vez, podemos decir que Xm va a ser Xi en el nuevo intervalo.

Iteración 4

Nuevamente tendremos un intervalo nuevo


NUEVO INTERVALO:

[ 1.375,1.5 ]


Tendremos que calcular nuevamente Xm

CALCULAMOS Xm:

Xm = 1.5 + 1.375 / 2 = 1.43


Una vez que tengamos Xm se calcula la tolerancia de error

ERROR:

| 1.43 - 1.375 / 1.43 | = 0.041 < 0.06


Es menor a 0.06 de tolerancia que buscamos, entonces las iteraciones se acaban aqui y no es tan necesario redefinir intervalos para una nueva iteración, sin embargo por esta vez vamos a redefinir los intervalos para ver que valores nos daba

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 1.43 ) = 1.43³ - 1.43² - 1 = - 0.12

f ( Xi ) = f ( 1.375 ) = 1.375³ - 1.357² - 1 = - 0.30


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados
para saber en la dirección que iban a tomar va nuevamente

- 0.12 * - 0.30 = 0.036


Como el resultado salio positivo, podemos decir que Xm iba a ser Xi en el nuevo intervalo.

EJERCICIO #3

Tenemos F(x) = x² - 5 encontrar la raiz con una tolerancia de 1/16 = 0.06



Iteración 1

Primero tendremos que evaluar las funciones de inicio y final, sin embargo en este caso no nos dan los intervalos para evaluar de primeras, entonces vamos a tener que hacer el tanteo de un numero que nos de negativo al ponerlo en la funcion y otro positivo asi sabremos que ese intervalo tendra una raiz en este ejemplo el intervalo fue [ 2,3 ]


EVALUAMOS:

f ( Xi ) = f ( 2 ) = 2² - 5 = - 1

f ( Xf ) = f ( 3 ) = 3² - 5 = 4


Despues de evaluar los intervalos, tendremos que calcular Xm

CALCULAMOS Xm:

Xm = 3 + 2 / 2 = 2.5


Ahora que tenemos Xm vamos a redefinir los intervalos para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 2.5 ) = 2.5² - 5 = 1.25

f ( Xi ) = f ( 2 ) = 2² - 5 = - 1


Una vez teniendo redefinidos los nuevos intervalos se van a multiplicar ambos resultados para saber en la dirección que va

1.25 * - 1 = - 1.25


Como el resultado salio negativo podemos decir que Xm va a ser Xf en el nuevo intervalo.

Iteración 2

Despues de hacer la primera iteración, se tendra que volver hacer casi el mismo
procedimiento para las demas iteraciones hasta llegar al error minimo deseado.


NUEVO INTERVALO:

[ 2,2.5 ]


Despues se tendra que calcular nuevamente Xm con los nuevos intervalos

CALCULAMOS Xm:

Xm = 2.5 + 2 / 2 = 2.25


Se va a calcular la tolerancia de error que se obtuvo en esta iteración y si se encuentra la raiz en esta iteración

ERROR:

| 2.25 - 2.5 / 2.25 | = | - 0.111 | = 0.111 > 0.06


como es mayor a la tolerancia entonces podemos seguir iterando y ya que tenemos Xm nuevamente vamos a redefinir los intervalos una vez más para la nueva iteración

REDEFINIMOS INTERVALOS:

f ( Xm ) = f ( 2.25 ) = 2.25² - 5 = 0.062

f ( Xi ) = f ( 2 ) = 2² - 5 = - 1


Siguiendo los pasos de la iteración 1, tendremos que multiplicar el resultado para saber en la dirección que va nuevamente y ver los intervalos nuevos:

0.062 * - 1 = - 0.062


Como el resultado salio negativo, Xm va a ser Xf en el nuevo intervalo.

Iteración 3

Siguiendo con las iteraciones, nuevamente tendremos un intervalo nuevo


NUEVO INTERVALO:

[ 2,2.25 ]


Tendremos que calcular nuevamente Xm

CALCULAMOS Xm:

Xm = 2.25 + 2 / 2 = 2.125


Una vez que tengamos Xm se calcula la tolerancia de error para ver si proseguir con las iteraciones y ya no redefinir los intervalos

ERROR:

| 2.125 - 2.25 / 2.125 | = | - 0.05882 | = 0.05882 < 0.06


Es menor a 0.06 de tolerancia que buscamos, entonces hasta aqui se deja de iterar

EJERCICIO #4

Tenemos F(x) = Cos(0.5e^-x) + x² - 2 encontrar la raiz en el intervalo [ - 1.9, -1.7 ] con un maximo de 6 iteraciones

Como el resultado salio positivo podemos decir que Xm va a ser Xi en el nuevo intervalo.
